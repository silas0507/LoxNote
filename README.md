# LoxNote

一个基于 Electron 的轻量级纯文本笔记应用。

## ✨ 功能特性

- **笔记管理** — 创建、编辑、删除笔记，自动保存
- **全文搜索** — 快速搜索所有笔记内容
- **标签分类** — 为笔记添加标签，按标签筛选
- **回收站** — 删除的笔记进入回收站，支持恢复或一键清空
- **内部链接** — 使用 `[[笔记标题]]` 链接到其他笔记
- **反向链接** — 自动显示哪些笔记引用了当前笔记
- **外部链接** — 自动识别 `http(s)://` 链接，支持 Ctrl+点击跳转
-  **历史版本** — 自动保存笔记历史版本，可随时回滚
-  **多种导出** — 支持导出为 TXT、Markdown、JSON、ZIP、PDF、HTML
- **主题切换** — 深色 / 浅色主题
-  **多语言** — 中英文支持
-  **自定义快捷键** — 自由配置常用操作的快捷键
-  **窗口控制** — 透明度调节、窗口置顶、记忆窗口大小与位置
-  **编辑器设置** — 字号调节、自动换行
-  **开机自启** — 可选随系统启动
-  **拖拽导入** — 拖入文件快速创建笔记
-  **查找替换** — 支持在当前笔记中查找和替换文本

## 🛠️ 技术栈

- [Electron](https://www.electronjs.org/) — 跨平台桌面应用框架
- 原生 HTML / CSS / JavaScript — 无前端框架依赖，轻量高效
- Node.js `fs` — 本地文件存储
